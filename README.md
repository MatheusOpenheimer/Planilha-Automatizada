
  O AutomatizaX foi desenvolvido para automatizar o lançamento de dados de pesquisas organizacionais em planilhas Excel de forma rápida, segura e padronizada.
  
  A aplicação permite selecionar:
  
  * a planilha de respostas do formulário;
  * a planilha principal da empresa;
  * a quantidade de perguntas no formulário
  * e a pesquisa desejada.
<p align="justify">
  Após a execução, o sistema identifica automaticamente a próxima linha disponível na aba correspondente e realiza o preenchimento das informações sem alterar fórmulas, filtros ou estruturas já existentes na planilha.
  Ademais, a quantidade de perguntas é coletada para que além de evitar erros, garanta maior flexibilidade e adaptação na aplicação, permitindo a personalização de fomulários e planilhas pelo usuário.
</p>
O objetivo do AutomatizaX é reduzir erros manuais, acelerar processos repetitivos e facilitar a consolidação de dados organizacionais.
